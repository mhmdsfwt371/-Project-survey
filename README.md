# متابعة المشروع — موسم ١٤٤٨هـ

منصّة ميدانية لمتابعة المسح وتركيب القارئات في المشاعر المقدسة، من تطوير **فريق أفاقي**.

تعمل من المتصفح ومن الهاتف بعد التثبيت، وتشتغل بلا إنترنت في الميدان وترفع نفسها تلقائيًا عند عودة الشبكة.

---

## ما تغطّيه

| | |
|---|---|
| نقاط التركيب | ‎~١٧٨٧ نقطة |
| المشاعر | منى · عرفات · مزدلفة · الجمرات · محطات القطار · مسجد نمرة |
| الفئات | مخيمات · ممرات · محطات · كاميرات · بوابات |

## الأدوار

| الدور | ما يفعله |
|---|---|
| **الفني / المشرف** | المسح الميداني، التركيب والتوثيق بالصور، اقتراح المواقع، التبليغ عن الموانع |
| **المهندس / إدارة المشروع** | الخطة والجدولة والإسناد، التدقيق الهندسي بالسيريال، العُهدة، مخاطبة الشركات |
| **الجهة الوزارية** | لوحة متابعة للقراءة فقط بأرقام لحظية وتقارير جاهزة للتصدير |

## البنية

- **الواجهة:** تطبيق ويب تقدّمي أحادي الملف — يعمل أوفلاين بالكامل
- **الخلفية:** Firestore للمزامنة اللحظية، و Firebase Authentication للأدوار
- **الخرائط:** Leaflet بطبقتَي خريطة وأقمار صناعية
- **النسخ الاحتياطي:** آلي يوميًا، **مشفّر** قبل النشر
- **التقارير:** إكسل و PDF و JSON للتكامل

## ضبط الجودة

كل إصدار يمرّ بـ:

1. فحص صياغة لكل كتلة برمجية
2. اختبار منطقي بمعطيات وهمية قبل النشر
3. حارس تطابق النسخ — يمنع النشر إن تخلّفت أي وثيقة عن رقم نسختها
4. حارس سلامة النسخ الاحتياطي — يُفشل العملية إن حاولت كتابة بيانات صريحة

## الخصوصية

المستودع عام لأغراض الاستضافة، ولذلك:

- **لا تُكتب بيانات الميدان فيه أبدًا كنص صريح** — النسخة الاحتياطية مشفّرة بمفتاح خارج المستودع
- الإيميلات والأسماء ونشاط الفريق والإحداثيات والصور كلها داخل Firestore محميّة بقواعد الوصول
- الصلاحيات بالدور: الفني لا يرى إلا شغله، والجهة الوزارية قراءة فقط
